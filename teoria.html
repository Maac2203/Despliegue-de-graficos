1. Uso de la etiqueta HTML <canvas> y Contexto 2D

La etiqueta <canvas> es un elemento de HTML5 que sirve como un lienzo gráfico en blanco donde se pueden dibujar gráficos, figuras y animaciones mediante JavaScript.

Para manipular el lienzo, se utiliza la API del contexto de renderizado 2D (getContext('2d')). Este contexto proporciona un plano de coordenadas cartesianas donde la esquina superior izquierda representa el punto (0,0). A través de este objeto se ejecutan métodos para dibujar trazados, rectángulos, arcos, texto y aplicar rellenos o bordes con color.

2. Fundamentos de la Librería p5.js

p5.js es una librería de JavaScript orientada a la programación creativa y enfocada en hacer el código gráfico accesible para artistas, diseñadores y estudiantes.

Su arquitectura básica se apoya en dos funciones globales principales:

  • setup(): Se ejecuta una sola vez al cargar la página. Aquí se inicializan el lienzo (createCanvas()) y los ajustes globales.
  • draw(): Se ejecuta continuamente en bucle (por defecto a 60 cuadros por segundo). Permite actualizar el lienzo y crear animaciones e interactividad en tiempo real.
